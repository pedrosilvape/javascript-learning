# JavaScript Learning

Repositório dedicado ao estudo e aprendizado de JavaScript, reunindo conceitos fundamentais, anotações, exemplos práticos e exercícios desenvolvidos ao longo da jornada de aprendizado.

## Objetivos

- Consolidar os fundamentos da linguagem JavaScript.
- Documentar conceitos e recursos da linguagem.
- Aplicar os conhecimentos por meio de exemplos práticos e exercícios.
- Desenvolver boas práticas de programação e organização de código.

## Tecnologias e ferramentas

- **JavaScript (ES6+):** linguagem principal de estudo.
- **Node.js:** ambiente de execução JavaScript utilizado no desenvolvimento e execução dos exemplos.
- **Git:** controle de versão.
- **GitHub:** hospedagem e gerenciamento do repositório.
- **Visual Studio Code:** editor de código.
