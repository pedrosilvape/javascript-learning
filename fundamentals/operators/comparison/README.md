# Comparison Operators

Estudo dos operadores de comparação em JavaScript, utilizados para comparar valores e verificar relações entre eles. O resultado dessas operações é um valor booleano (`true` ou `false`).

## Conteúdo

- **Igualdade (`==`):** verifica se dois valores são iguais, permitindo conversão de tipo.
- **Diferença (`!=`):** verifica se dois valores são diferentes, permitindo conversão de tipo.
- **Maior que (`>`):** verifica se um valor é maior que outro.
- **Menor que (`<`):** verifica se um valor é menor que outro.
- **Maior ou igual (`>=`):** verifica se um valor é maior ou igual a outro.
- **Menor ou igual (`<=`):** verifica se um valor é menor ou igual a outro.
- **Igualdade estrita (`===`):** verifica se dois valores são iguais, considerando também o tipo.
- **Diferença estrita (`!==`):** verifica se dois valores são diferentes, considerando também o tipo.
