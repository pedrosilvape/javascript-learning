# Logical Operators

Estudo dos operadores lógicos em JavaScript, utilizados para combinar ou inverter condições booleanas, permitindo criar verificações mais completas.

## Conteúdo

- **AND (`&&`):** retorna `true` quando todas as condições são verdadeiras.
- **OR (`||`):** retorna `true` quando pelo menos uma das condições é verdadeira.
- **NOT (`!`):** inverte o valor lógico de uma condição.

## Aplicações práticas

- Combinação de condições.
- Verificação de login e senha.
- Controle de acesso.
- Inversão de valores booleanos.
- Construção de condições compostas.
